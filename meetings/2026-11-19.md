## Meeting Notes

### This Week in HLSL

There were 48 PRs merged in HLSL-related areas this week.

* The HLSL frontend added Shader Model 6.10, QuadAll emulation, DebugBreak,
  more matrix support, and improvements to language diagnostics and rules.
* The DirectX backend gained debug-break lowering and improved vector operand
  splitting.
* The SPIR-V backend saw extensive legalization and lowering improvements for
  pointers, vectors, fixed-point operations, workgroup memory, and function
  signatures.
* The offload test suite added coverage for the WaveMultiPrefix intrinsics and
  matrix operations, enabled arm64 artifact builds, and removed stale XFAILs.
* HLSL now defaults to language version 2021, and the SPIR-V driver defaults to
  the DXC extension set.

38 new PRs were opened, and there are 93 ongoing PRs.

For a full list of merged PRs, see the appendix.
