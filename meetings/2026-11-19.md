## Meeting Notes

### This Week in HLSL

There were 44 PRs merged in HLSL-related areas this week.

* clang-dxc now defaults to HLSL 2021.
* clang-dxc's SPIR-V extension set now matches DXC by default.
* HLSL had Shader Model 6.10 added and language and diagnostics improvements.
* The DirectX backend learned debug-break and cleaned up spurious vector
  instructions.
* SPIR-V saw various legalization and lowering improvements.
* The offload test suite added new wave and matrix tests.

38 new PRs were opened, and there are 93 ongoing PRs.

For a full list of merged PRs, see the appendix.

### Default SPIR-V Extension Set

There was some fallout in the offload test suite from changing clang's default
SPIR-V extension set to match DXC. We realized that we were unintentionally
testing the scalarization path of long vectors when targeting Vulkan, rather
than enabling the extension. @dnovillo is following up with a PR to explicitly
enable long vectors on those tests.

This brought up the broader issue of how we want to handle the interface for
enabling extensions like this universally. The shader model abstraction makes
sense for DirectX, but doesn't map well to Vulkan and the attempts to paper
over this in DXC were mostly ad hoc. See llvm/llvm-project#242027 for follow
ups on this.
