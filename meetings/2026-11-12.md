## Meeting Notes

### This Week in HLSL

There were 41 PRs merged in HLSL-related areas this week.

* In the HLSL frontend several wave intrinsics were added, there was long
  vector and matrix work, and there were code cleanups and bug fixes.
* The DirectX backend saw vector reduction lowering and generalization of
  integer legalization, as well as more work towards adopting the new pass
  manager.
* SPIR-V had some resource cleanup, work on type tracking, and various cleanups
  and fixes.
* In the offload suite there were the usual XFAIL updates and some focus on
  getting the lavapipe pipelines clean.

43 new PRs were opened, and there are 75 ongoing PRs.

For a full list of merged PRs, see the appendix.
