## Meeting Notes

### This Week in HLSL

This week had 23 PRs merged in HLSL.

In HLSL we had texture improvements and we added more long vector intrinsics.
In DirectX we saw semantic signature packing and DXIL op lowering improvements.
SPIR-V saw improvements to legalizing implicit bindings and unbounded arrays as
well as some debug improvements and bug fixes. The offload suite saw a number
of tests added for matrices as well as a bug fix with odd numbers of 16-bit
types on DirectX.

There were 27 new PRs opened, and there are 68 PRs currently ongoing.

For a full list of merged PRs, see the appendix.
