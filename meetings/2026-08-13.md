  - Several HLSL functions are now implemented in the HLSL headers

For a full list of merged PRs, see the appendix.

### Long Vector Implementation in Clang

@farzonl walked us through the plan for implementing HLSL long vector support
in clang. It looks like most of the work here will be in updates to tablegen,
and then we can move on to implementing and testing the elementwise intrinsics.
For non-elementwise intrinsics like dot product we'll probably want to
implement the handling in intrinsic expansion, as doing these in the frontend
would need some awkward shader model specific macro tests.

* [HLSL][Tablegen][LongVec] Add a means of generating vector templates
  (llvm/wg-hlsl#462)
* [HLSL][longvec] Add longvector support for elementwise intrinsics in the
  frontend (llvm/llvm-project#216103)
* [HLSL][LongVec] Make a long Vector Dot product (llvm/llvm-project#216094)
