## Meeting Notes

### This Week in HLSL

There were 39 PRs merged in HLSL-related areas this week.

* The HLSL frontend added a few semantics and matrix support for `step`.
* The DirectX backend was largely unchanged, only seeing miscellaneous cleanup.
* The SPIR-V backend saw various bug fixes and efforts to re-enable spirv-val,
  as well as some new lowerings.
* The offload test suite received several tests for derivatives and removed
  stale XFAILs.
* New pass manager work continued for both DirectX and SPIR-V, including
  ports of several DirectX passes and SPIR-V pipeline improvements.

30 new PRs were opened, and there are 75 ongoing PRs.

For a full list of merged PRs, see the appendix.
