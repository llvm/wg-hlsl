## Meeting Notes

### This Week in HLSL

This week had 37 PRs merged in HLSL:

- **HLSL Frontend**
  - Several congergent intrinsics were marked as convergent
  - The long-vector work has started
  - Matrix compare support was added
  - Bug fixes
- **DirectX Backend**
  - Several issues with phi nodes were fixed in dxil-resource-access
  - The AdvancedTextureOps flags was implemented for samples
- **SPIR-V Backend**
  - Calling conventions for intrinsic calls were fixed
  - Various bug fixes and lowering improvements
- **Offload Test Suite**
  - Dynamic resource tests are now possible
  - Support for writing SM 6.9 tests is in progress
  - Infrastructural improvements for testing and test monitoring
- **Other**
  - Clang docs are being moved to markdown
  - CodeGen GlobalISel seems to finally be happening

There were 32 new PRs opened, and there are 54 PRs currently ongoing.

For a full list of merged PRs, see the appendix.
