## Meeting Notes

### This Week in HLSL

The DirectX backend is being promoted from experimental to an official backend!

This week had 43 PRs merged in HLSL. This includes work on long vectors,
dynamic resources, and various intrinsics. We also saw support for SM 6.9 added
to the offload suite, more documentation migration to markdown, and work on
porting GlobalISel to the new pass manager.

There were 31 new PRs opened, and there are 63 PRs currently ongoing.

For a full list of merged PRs, see the appendix.

### Ambiguous Overloads

We discussed ambiguous overloads, such as `max(float, int)` and whether we need
to change our strategy around them. So far we've generally been adding
compatibility overloads in clang where we see cases that run into a lot of use,
and there wasn't much appetite to change the approach here.

### Requests for Review

There were no specific requests for review this week.
