## Meeting Notes

### What's Happening in HLSL

From September 17th to Octbober 1st there were 87 PRs merged in HLSL-related
areas.

* HLSL Frontend
  - The SV_InstanceID semantic was implemented
  - Dynamic resource support was added
  - A number of atomic functions and resource methods were implemented
  - Packed types were added
  - Matrix support was improved and expanded upon
* DirectX Backend
  - Atomic support was improved
  - Resource handling was improved for updatecounter, 64-bit
    ByteAddressBufferAccesses, doubles, non-unique resources, and UAV texture
    loads.
* SPIR-V Backend
  - Various legalization and lowering improvements were made
  - Some tests were audited for proper check lines and spirv-val usage
* Offload Test Suite
  - Many tests were added
  - Variable rate shading support is now testable
  - Various XFAILs were removed
* Other
  - The NewPM for CodeGen work continues
  - Some more canonical GEP work has landed

46 new PRs were opened, and there are 56 ongoing PRs.

For a full list of merged PRs, see the appendix.
