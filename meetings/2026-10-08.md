### What's Happening in HLSL

From Octbober 1st to Octbober 7th there were 27 PRs merged in HLSL-related
areas.

* HLSL Frontend
- Compatibility overloads for scalar min/max

* DirectX Backend
- sv_barycentrics intrinsic support
- Cast the pointer for atomics

* SPIR-V Backend
- various fixes not related to HLSL
- Split wide vector intrinsics during legalization (should make more matrix tests pass)
 
* Offload Test Suite
- `select` matrix tests are on for clang
- isfinite() tests are in
- various other xfails were removed


17 new PRs were opened, and there are 75 ongoing PRs.

For a full list of merged PRs, see the appendix.
