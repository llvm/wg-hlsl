## Meeting Notes

### This Week in HLSL

This week had 45 PRs merged in HLSL.

The DirectX backend is no longer experimental! Thanks to everyone's hard work
to make this happen. The HLSL frontend saw matrix and long vector support
improvements as well as progress on Texture types. In SPIR-V we saw various
legalization and lowering improvements, as well as more work on the NewPM
migration.

There were 15 new PRs opened, and there are 56 PRs currently ongoing.

For a full list of merged PRs, see the appendix.

### Ambiguous Overloads

We followed up on ambiguous overloads of `max` and `min`, and agreed that
adding compatibility overloads for these probably makes sense. @pow2clk will
create a pull request.

### IsTokenLike and Resource Target Types

A discussion on [semantics of target extension types] pointed out that there
are inconsistencies with how DirectX resource types are using `IsTargetType`.
@bogner explained that we found that attribute insufficient to handle
everything that HLSL allows and we had to implement solutions separately
anyway. Because of this we're going to drop it from the resource types
entirely.

[semantics of target extension types]:
  https://discourse.llvm.org/t/directx-and-the-semantics-of-target-extension-types/91708

### Vulkan Target Environment Support

@pow2clk asked if there were strong reasons that we're only supporting vulkan
target environments of 1.2 and higher. @llvm-beanz recalled that @s-perron
chose this as a baseline because it generally has broad support, and that there
wasn't a particularly strong reason to exclude 1.1 other than that we may not
need it.

### HLSL Pack/Unpack Math Intrinsics

@Alexander-Johnston noted that the DirectX documentation for [Pack/Unpack Math
Intrinsics] only state they can be converted to and from `uint32_t` values, but
DXC's support is much more permissive. @llvm-beanz pointed out that there are
existing HLSL modifications to the usual arithmetic conversions that are
applicable if we need to support the more permissive set of conversions for
compatibility.

[Pack/Unpack Math Intrinsics]:
  https://microsoft.github.io/DirectX-Specs/d3d/HLSL_SM_6_6_Pack_Unpack_Intrinsics.html

### Requests for Review

No particular pull requests were called out this week.
